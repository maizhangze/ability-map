# 能力地图 · 18 岁大学生全面发展能力自评工具

一个单文件网页（无依赖、无后端、离线可用），把「17 个一级维度 / 209 项子能力」的自我评估流程做成可以真正填完、并且能导出给 AI 分析的工具。

打开 `能力地图.html` 即可使用，不需要安装任何东西，也不需要联网。

---

## 为什么做这个

常见的自我评估表有两个问题：一是让人一次性给十几个领域打高分，打完就忘；二是分数之间没有权重，看不出「哪一项该先补」。

这个工具针对这两点做了处理：

- **拆到可观察的行为**。不评「沟通能力」，而是评「主动开口」「提出请求」「拒绝能力」这样能对应到具体行为的小项，避免用「我知道这回事」代替「我做得到」。
- **能力和重要程度分开评**。每项能力打 1–5 分（P），每个维度再单独评估对未来 1–3 年的重要程度（I），由此得出「优先补足 / 重点利用 / 保持优势 / 暂缓提升」的策略。
- **允许「未验证」**。没有真实经历过的事，可以不给自己打分，标记为未验证，不参与均分计算。
- **结果可以带走**。导出带名称的 JSON，直接交给 AI 做分析。

## 功能

| 页面 | 内容 |
| --- | --- |
| 评估 | 17 个维度、209 项子能力逐项打分；每项 1–5 分 + 未验证；每个维度设重要程度与半年趋势（↑ → ↓）；实时计算维度均分与完成进度 |
| 总表 | 17 维度一览：均分 P、重要程度 I、趋势、自动判定的策略；可按任意列排序；自动列出「重要程度 ≥ 4 且得分 ≤ 3」的具体能力缺口 |
| 优先级 | P × I 四象限矩阵，把 17 个维度自动归入四个策略区；中间地带（P ≈ 3）单独列出，标注「未来瓶颈」或「第二梯队」 |
| 总结 | 最强三项、最需补足三项、最易忽视的短板、最缺乏的现实经历、未来一年三个目标等 |
| 8 周计划 | 短板提升 / 第二短板 / 优势利用 / 基础维护四条线，各配 8 周目标与每周节奏；附三个季度复盘问题 |

其他：

- 所有输入自动保存到浏览器本地（localStorage），关掉页面再打开还在
- 支持导出 JSON、CSV，打印或另存为 PDF
- 移动端可用，左侧目录在小屏上折叠为抽屉

## 评分规则

能力分（P，每项子能力独立打分）：

| 分数 | 含义 |
| --- | --- |
| 1 | 几乎不具备，通常无法独立完成 |
| 2 | 能理解基本方法，但实际执行困难 |
| 3 | 基本具备，普通场景能够完成 |
| 4 | 熟练掌握，复杂场景也能稳定运用 |
| 5 | 明显突出，能够灵活应用、总结方法，甚至指导别人 |

重要程度（I，每个维度一个分数，评价的是未来 1–3 年的重要性，不是能力本身）：

| 分数 | 含义 |
| --- | --- |
| 1 | 暂时不太重要 |
| 2 | 有一定价值，但不急迫 |
| 3 | 比较重要，值得保持 |
| 4 | 非常重要，需要主动投入 |
| 5 | 核心能力，明显影响长期发展 |

策略判定：

- P < 2.5 且 I ≥ 4 → **优先补足**（重要短板，优先投入时间）
- P ≥ 3.5 且 I ≥ 4 → **重点利用**（把优势用到更多场景，形成竞争力）
- P ≥ 3.5 且 I ≤ 3 → **保持优势**（不必过度投入，留作个人特色）
- P < 2.5 且 I ≤ 3 → **暂缓提升**（维持基本水平即可）
- P ≈ 3 时：I = 5 视为**未来瓶颈**，I = 4 视为**第二梯队**

> 没有经历过的事情，不建议直接给自己 5 分。可以标记为「未验证」，之后通过实际经历检验。

## 数据导出

**数据 → 导出** 菜单提供四种方式：

| 方式 | 用途 |
| --- | --- |
| 导出 JSON（含能力名称） | 完整数据，可直接发给 AI 分析；同时保留可再次导入的原始备份 |
| 导出 JSON（不含编号） | 去掉 `1.1`、`1.2` 这类编号，避免被误读成分数；仅用于分析，不能导回 |
| 复制文本报告（发给 AI） | 精简 Markdown，只列已评分项，适合直接粘贴到对话框 |
| 导出 CSV | 带 BOM，Excel 直接打开不乱码 |

导出的 JSON 结构示例（节选）：

```json
{
  "dimensions": [
    {
      "name": "身体健康与体能",
      "importance": 5,
      "importanceLabel": "核心能力，明显影响长期发展",
      "averageScore": 2,
      "strategy": "优先补足",
      "abilities": [
        {
          "name": "睡眠管理",
          "question": "能否保持相对稳定的作息？能否识别影响睡眠的因素？",
          "score": 2,
          "status": "rated",
          "level": "能理解基本方法，但实际执行困难"
        }
      ]
    }
  ]
}
```

`status` 有三种取值：`rated`（已评分）、`unverified`（未验证）、`unrated`（未评分），后两者的 `score` 均为 `null`，不参与均分计算。

文件里还内置了 `readingGuide`（评分标准说明）和 `analysisPrompt`（一段可以直接交给 AI 使用的分析指令）。

## 隐私

- 所有数据只保存在本机浏览器的 localStorage 里
- 页面不发起任何网络请求，不加载任何第三方库、字体或统计脚本
- 「清空全部结果」会同时清除本地存储

---

## 使用与分享

本地双击 `能力地图.html` 打开即可。

如果希望别人直接通过链接访问：

1. 把仓库设为 Public
2. 将 `能力地图.html` 重命名为 `index.html`
3. 在 Settings → Pages 中选择 `main` 分支的根目录

---

## 说明

这个工具只做「结构化自评 + 优先级判断」，不构成任何专业评估结论。它的价值不在于得到一张漂亮的高分表，而在于准确指出下一步应该做什么；建议每 3 个月重做一次并对比。
